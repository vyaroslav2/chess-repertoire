### B2.02 — Set up the engine-score variables

**What the code does**  
B2 creates the values it will use while gathering engine data:

- `enginePvs = []`  
    The main list of engine moves and scores. Later boxes fill this from the currently preferred engine source.
    
- `chessdbPvs = []`  
    A separate list of ChessDB moves and scores. ChessDB is kept separately because later logic may compare or use it independently.
    
- `bestCp = 0`  
    The best engine evaluation currently known for the position. `Cp` means **centipawns**.  
    For example:
    
    - `+100` = about +1 pawn for White;
        
    - `-100` = about +1 pawn for Black.
        
    
    It starts at `0` only as an initial placeholder.
    
- `lichessCp = null`  
    The best Lichess Cloud Eval score, if one is obtained.  
    `null` means no Lichess score has been obtained yet.
    
- `chessdbCp = null`  
    The best ChessDB score, if one is obtained.  
    `null` means no ChessDB score has been obtained yet.
    
- `evalSource = "Lichess"`  
    The label saying which source is currently treated as the main evaluation source. It starts as `"Lichess"` and can later change to `"ChessDB"`.
    

Nothing is fetched or selected in this box.

After that, B2 continues to [[B2.03]].

**Why this matters**  
These variables keep the different engine results separate while B2 works out which source and scores are available.

Notes:

#note `bestCp = 0` does not mean the position has actually been evaluated as equal. At this point it is only the initial value before real engine data is loaded.
