### B2.03 — Check the engine-evaluation cache

**What the code does**  
B2 looks in `EngineEvalCache` for saved engine evaluations for the current position.

The lookup uses the position's **normalised FEN**.

==It asks for all matching rows, ordered by their saved rank.[^1]==

So at this point B2 is simply asking:

> "Do we already have engine data for this position?"

If cached rows exist, B2 follows the cache branch.

If none exist, it follows the fresh-fetch branch.

After this check, the flow continues according to that result.

**Why this matters**  
This avoids unnecessary API or engine work when the position has already been evaluated.
