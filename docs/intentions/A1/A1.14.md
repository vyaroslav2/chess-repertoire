### A1.14 — Is the queue empty?

**What the code does**
The loop's one question, asked before every position. If the queue still holds something, the run takes the next item and carries on. If it is empty, the run is over and moves to the summary in [[A1.15]].

Nothing else ends the loop. There is no time limit, no limit on how many positions may be processed, and no way to ask it to stop.

**Why this matters**
This is the only definition of "finished" the generator has: the queue ran dry. A run ends when there is nothing left within the depth cap that has not already been seen.

That makes the length of a run impossible to predict before starting it. How long it takes depends on how many positions pass the filters, which depends on the openings people actually play. You find out by watching the log.

Since nothing can interrupt it, stopping a run means killing the process — which strands the lock, as described in [[R.03]], and leaves the log without its closing marker. There is no polite way to say "stop after this position".[^1]

The loop also has no protection against never finishing. Today the depth cap guarantees an end, because the tree below three moves is finite. If the cap were raised a long way, or the trap counter allowed lines to run further, nothing here would notice a run that had been going for a day.[^2]

**Why it may have been designed this way**
Known: the queue emptying is the natural end for this kind of walk through a tree, and with a fixed depth cap it is guaranteed to happen.

Notes:

[^1]: #roadmap Today the only way to stop one is to kill it, which strands the lock and leaves the log unfinished. A gentle version would notice a request between positions and then finish normally — releasing the lock, closing the log properly. Worth having if runs ever become long; not urgent while they are short.

[^2]: #note Nothing here limits how long a run may take or how many positions it may process. The depth cap is what guarantees an end today. If the cap were raised substantially, that guarantee would be the only thing standing between you and a run of unknown length.
