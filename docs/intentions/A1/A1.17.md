### A1.17 — Write the history out as one line

**What the code does**
The item's move history — a list of moves — is joined into a single line of text with spaces between, such as "e4 c6 d4 d5". That line is this position's identity for the rest of the loop.

It is used twice: to look the position up in the visited list at [[A1.18]], and to add it there at [[A1.19]].

The same joining is done again later, in [[A4]], when a node is created or looked up in the database. Both places produce the same text from the same moves, but neither borrows it from the other.

**Why this matters**
This is what makes "have we seen this before" answerable. A list of moves cannot easily be compared with another list, but two lines of text either match or they don't.

It also means the identity is the *sequence*, not the position. Two move orders reaching the same board produce two different lines, so the run treats them as two different things and expands both. That is the same rule the database uses for nodes, and it is why the tree has one path into each node.

Because the joining happens in more than one place, the identity depends on both places agreeing. They do today — same moves, same separator, same order — but nothing enforces it. If one were ever changed to join differently, the visited list and the database would quietly disagree about what counts as the same position, and the run would do work twice while believing it had not.[^1]

**Why it may have been designed this way**
Known: joining with spaces produces exactly the standard way of writing a game's moves, which is also what is stored on each node. So the identity is readable, and matches what you see in the log and in the database.

**Also affects:** [[A1.18]] (which compares it), [[A1.19]] (which stores it), [[A4.06]] (which extends the history), [[RM.01]] (which looks nodes up by the same text)

Notes:

[^1]: #note The same line of text is produced independently here and in [[A4]], and everything depends on the two agreeing. They do today. Worth knowing if either is ever changed — the two would disagree silently, and the run would repeat work while believing it had not.
