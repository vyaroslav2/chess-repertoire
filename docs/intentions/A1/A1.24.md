### A1.24 — Print the per-position checkpoint

**What the code does**
After every position has been dealt with, five lines are printed: a heading saying a node has finished, then the elapsed time with the positions and abandoned branches so far, then the White moves found with their breakdown into skipped, mainlines, traps and threats, then the two missing-move totals, then a line of dashes.

Every figure on it is a running total for the whole run. Nothing on it describes the position just finished.

The heading marks itself as temporary.

**Why this matters**
This is the second of two reports printed per position, and it repeats what [[A1.20]] already gave you at the start of the same position. Between them, eight lines are printed for every position, most of them the same numbers a moment apart.1

Because everything on it is a running total, it does not tell you what the position just finished actually produced. You can work that out by subtracting the previous checkpoint from this one, which is not something anyone does while reading a log.2

It is printed for positions that were dealt with, but not for those abandoned by the depth or trap limits in [[A2]] — those return to the loop before reaching this point. So the checkpoints appear at uneven intervals, and a run of abandoned positions produces the running lines from A1.20 without a checkpoint after them.

The word temporary in the heading is the most informative thing on it: this was added while working on something, and never taken out.3

**Why it may have been designed this way**
Known: it labels itself temporary, so it was a debugging aid rather than part of the intended output.

Likely: it was added to watch the counters move without waiting for the summary at the end, at a time when runs were failing part way through and the summary was rarely reached.

**Also affects:** [[A1.20]] (the report at the start of the same position), [[A1.15]] (the summary, which prints the same figures once), [[A1.25]] (where these counters start), [[A2.12]] and [[A2.18]] (abandoned positions, which skip this)

Notes:

1 #note Kept deliberately. Every figure here also appears in the summary at [[A1.15]], but seeing the totals climb during a run is worth the extra log length. The word "temporary" in the heading should be removed when the code is next touched, since it is now a permanent, decided part of the output.

2 #note Every number on this line is a running total, so the checkpoint says nothing about the position just finished. What that position produced can only be found by comparing this checkpoint with the one before it.

3 #note The heading says temporary. Whatever it was added to investigate has been resolved or forgotten; it has simply stayed. Worth deciding deliberately rather than leaving it to be inherited.
