### A4.09 — Found one, and does it already have a saved training card pointing to a Black reply?

**What the code does**  
This box is reached only if [[A4.08]] found an existing repertoire node for the position after White's move.

A4.08 asks Prisma to load that node together with its `stats` records.

A4.09 then checks:

`posAfterWhiteNode.stats.length > 0`

So:

- one or more stats records -> yes;
    
- no stats records -> no.
    

In this project, a `RepertoirePositionStat` record is the saved training-card record for a repertoire position. It contains, among other things, a `targetMoveId` pointing to the Black reply the user is meant to learn from that position.

So conceptually this box asks:

"Has this position already been expanded far enough that a Black response has been chosen and saved as its training card?"

If the answer is yes, the algorithm takes the transposition-merging path to [[A4.11]].

If the answer is no, the existing node is reused and the algorithm continues through [[A4.10]] rather than creating a duplicate node.

**Why this matters**  
Finding the same position is not enough by itself to know what to do with it.

There are two different cases:

- the position already has a training card and chosen Black reply;
    
- the position exists as a repertoire node, but has not yet been fully expanded into a training card.
    

The first case can reuse the already-known continuation.

The second still needs Black's reply to be worked out later.

This distinction is important for transpositions because reaching an already-trained position should not create another flashcard for the same position.

**Why it may have been designed this way**  
Known: the intention is to avoid duplicate SRS cards when different move histories reach the same training position.

A node with a saved training card already knows the Black move to learn, so the new route can merge into that existing position rather than evaluating and creating the same card again.

An existing node without a card cannot yet be treated as fully expanded, so it still needs to continue through the normal Black-move path.
