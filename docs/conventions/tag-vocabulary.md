Tags go on footnotes in the intention notes, one tag per footnote, always first.
If a footnote seems to need two tags, it holds two things — split it.

#note — something to remember. No action implied.
#bug — behaviour that contradicts intention. Needs fixing.
#roadmap — something wanted that does not exist yet.
#deferred — looked at and consciously put away. Say what would bring it back.
#question — still open. Should not survive the end of a session.
#fixed — was a bug, now resolved. Keep the text, add the date.
#glossary — on glossary notes only, marking a term specific to this project.
