# Step 1: Start Run / Lock Check

S1.01 Start a generation run. Registering the stop listener comes first ([[S0|S0.01]]), so Ctrl+C is caught from here on.

S1.02 Acquire the lockfile ([[LF]]).
* Acquired `-->` continue.
* Refused `-->` stop. The message appears in the console only. 

S1.03 Open the run log. Route every message from here on to both the console and the log file ([[TGL]]).[^1] Each run writes its own file, so earlier runs are never touched.

S1.04 Continue to [[S2]].

[^1]: This used to name a single fixed file, `new-docs\logs\TreeGenLog.md`. That name was stale: [[TGL]] says one file per run, and [[file-naming]] item 13 gives the form `treegen-2026-08-30T111523Z.md`. Item 9 also says `logs/` is not committed.
