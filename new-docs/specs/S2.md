# Step 2: User, Repertoire, Wipe, Seed Queue

S2.01 Print the startup message[^1], start the timer, zero out the run counter `tinyDroppedTotal`. `rareDroppedTotal` and `unaccountedDroppedTotal` are not counters: they are summed from the nodes whenever they are needed.

S2.02 Find in the DB the user `Yaroslav`, or create that user if missing.[^2] 

S2.03 Find in the DB Yaroslav's repertoire titled "Black Universal Repertoire"; if missing, create it with colour Black.

S2.04 Wipe the previously generated tree for this repertoire — nodes and moves ([[DB|DB.02]]) — and the `Position` table built from them ([[DB|DB.36]]).[^3] What survives is every cache: Explorer data, engine evaluations, opening metadata and Wikibooks text ([[DB|DB.30]]).

S2.05 Create the root node: the starting position.

S2.06 Set the [[root-probability|root's probability]] -- 100%. Both `routeProb` and `cumProb`; at the start of a run every node has one equal to the other ([[TR.excalidraw|TR]]).

S2.07 Put the root into the queue. Continue to [[S3]].


[^1]: See [[TGL]]

[^2]: #note `userName`, `repertoireTitle`, `repertoireColour` are deliberately hardcoded.

[^3]: #note Wipe and rebuild is the intended truth. No reconciliation.
