# Step 2: User, Repertoire, Wipe, Seed Queue

S2.01 Print the startup message[^1], start the timer, zero out the run counters -- `rareDroppedTotal` and `tinyDroppedTotal`.

S2.02 Find in the DB the user `Yaroslav`, or create that user if missing.[^2] 

S2.03 Find in the DB Yaroslav's repertoire titled "Black Universal Repertoire"; if missing, create it with colour Black.

S2.04 Wipe the previously generated tree for this repertoire — both [[node|nodes]] and moves ([[DB|DB.02]]).[^3] What survives is every cache: Explorer data, engine evaluations, opening metadata and Wikibooks text ([[DB|DB.30]]).

S2.05 Check whether the root position exists in the Explorer cache (`PositionCache`, [[EX|EX.01]]) — reuse it or create it.[^4]

S2.06 Set the [[root-probability|root's probability]] -- 100%. Both `routeProb` and `cumProb`; at the start of a run every node has one equal to the other ([[TR.excalidraw|TR]]).

S2.07 Put the root into the queue. Continue to [[S3]].

S2.08 #question  The `Position` table — the `positionKey` to owning-node index that [[TR.excalidraw|TR.03]] matches on — is not mentioned here, and [[DB|DB.02]] only wipes nodes and moves. It has to be wiped as well.[^5]
