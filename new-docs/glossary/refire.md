**Refire** — within one [[cascade]], a node passes a gain to the same child a second time, with a different amount. Found in [[applied-items|appliedItems]]: the same fromNode and toNode, but a different gainOnThisItem.

Not an error. 

Counted in `refires` and logged when the cascade completes.

Not the same as a [[duplicate]], where the gain is the same too.
