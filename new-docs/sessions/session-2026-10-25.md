## Decisions
- No fallback to the previous name in the trainer for a missing status: after a transposition it would show the wrong opening. A name Explorer doesn't have is already copied from the parent when stored (DB.06 rule 2), so the data is right and the trainer only reads it.
- No rule for Anki cards whose line isn't in the database. Every card comes from the database; a hand-made one would at worst show no name until its last move.
- "1 in N" is a whole number. cumProb is an estimate, so rough is fine early on. Only 67% and up would show "1 in 1", and in `dev.db` no position after the start is that high (1.e4 is 64%). One decimal below 10 was tried first and dropped. Showing % for the first move only was dropped too: one format is easier to scan.
- Hotkeys by position, not by letter: no need to check the layout before pressing a key. The cost, keys not matching their labels on AZERTY or Dvorak, doesn't apply: ЙЦУКЕН sits on QWERTY's keys. Digits and Enter stay `e.key`; they are the same on both.
- Probability placement kept: one line with the name, right-aligned with the board. Not in the move list panel, away from the position it describes. A tooltip ("Reached in 1 of 4.1 games") was offered and not taken for now.
