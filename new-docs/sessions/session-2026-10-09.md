## Decisions
- Rules-infraction games are dropped by the filter only; `load` does not check again.
- ECO and opening name are labels, not requirements: a missing one is stored as `?`.
- `final_state` uses `undefined`, not NULL, so a bug cannot hide behind an empty value.
- `stop_reason` stays an ENUM, not a separate table.
- `ascii_bin`, not a hash, keeps IDs and SAN moves case-sensitive.
- No `hash_uci` column until a query needs it.
- More data means a new download from byte 0; "continue" is deferred.
- Run names give the month and the bytes downloaded: `2024-01-2500mb`.
- Black plays local Stockfish 19's top move, unless a hardcoded response applies. Human candidates, the Black score and the cp tolerances are gone.
- Explorer fetches the Amateur dataset only, for White's moves. Masters and Elite are gone.
- `deepVerified` is gone: there is no API move left to verify.
- The Stockfish version is part of the engine cache profile (`localStockfishVersion`).
- Removed block IDs are not renumbered. The gaps stay, so links elsewhere stay correct.
- [[HE]] is roadmap, so it was left out of the sweep.
- EW is retitled "Engine Response". The ID stays `EW` and no longer stands for anything, so no links change.
