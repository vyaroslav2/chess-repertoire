## Decisions
- 20 cards: the top 20 by `cumProb`, the positions most likely to be met.
- Profile `User test New` while testing, so test grades never mix with the real decks or AnkiWeb sync.
- The key is SHA-1 of the moves (UCI), not database ids: a rebuilt tree gives the same keys.
- Our cards are found by note type, not deck name ([[AK|AK.06]]): AnkiWeb sync carries the note type to a new computer, and a renamed deck still works.
- Anki's reviewer, not `answerCards`: Anki picks the order, with its learning steps and limits, and times each answer. With `answerCards` the app would pick the order and Anki would log every answer as 0s. The cost: Anki's window sits on the review screen.
- No 30s polling: the app asks Anki on each page load and after each grade, so it never holds a stale card.
- Evals and openings are read from the database by line, read-only. A line not in the database still works, with the card's own opening and no evals. Card state stays in Anki.
- The app does not switch Anki profiles: switching is asynchronous, and loading the open profile stops AnkiConnect.
- Undo takes back only grades made on the page: Anki's undo would take back anything.
- No tags on the notes: the note type already finds our cards.
- The export script refuses a tree being built: it is wiped and only half there.
- Grading has its own spec, [[GR]]: it covers both pages, and it isn't about Anki.
- `1`–`4` grade straight after a wrong move, without the answer shown, as Anki allows ([[GR|GR.04]]). Before any move, they do nothing.
- During the intro, only `Enter` acts: one press shows the answer, and `Enter`, `Enter` passes over a card quickly. `1`–`4` have nothing to grade yet, so they leave the slide alone ([[GR|GR.01]]). To watch in use: whether `Enter`, `Enter` reveals answers too soon.
- A wrong undo is caught by the card's review count: if it doesn't go down, Anki undid something else. The page then blocks undo until reload ([[AK|AK.13]]). Anki's Redo brings the edit back.
- A web page can't read or change Anki's tooltips; only an Anki add-on can. An add-on looks unavoidable, since Anki's tooltips are to be polished anyway ([[AK|AK.13]]). It would add its own action to AnkiConnect, on the same port, and change the tooltip only for undos from the page, not for Anki's own `Ctrl + Z`.
