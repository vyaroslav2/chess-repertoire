# Общий кэш оценок: экспорт и импорт

`sc_exchange.py` обменивается оценками Stockfish между твоей таблицей `calculations` и моим проектом. Правила — в SCR.50–57.

## Установка

Нужен Python 3.8 или новее.

```bash
python -m pip install chess mysql-connector-python
```

В начале `sc_exchange.py` проверь `DB_CONFIG` и `TABLE_NAME`: хост, порт, базу и таблицу. Пароль скрипт спросит сам. Можно и задать его заранее, в переменной `SC_MYSQL_PASSWORD`; пользователя — в `SC_MYSQL_USER` (по умолчанию `root`).

## Экспорт

```bash
python sc_exchange.py export
```

Пишет все посчитанные строки в `exports/evals-ГГГГ-ММ-ДД.json`. Строки, где `uci` пуст, ещё не посчитаны, поэтому не попадают в файл. Нули в `cp` и `mate` становятся `null` (SCR.57). Если хоть одна строка нарушает правила SCR.55, файл не пишется, а скрипт называет эти строки по `id`.

## Импорт

```bash
python sc_exchange.py import evals-2026-11-13.json
```

Сначала проверяется весь файл, потом всё пишется одной транзакцией: либо целиком, либо никак (SCR.53).
* Новая позиция добавляется новой строкой, с `hash` и `ponder`, как их делает Colab.
* Если позиция уже стоит в очереди (`uci` пуст), строка заполняется. Colab её больше не считает.
* Позиция, которая уже посчитана, должна совпасть во всех полях. Если хоть одна расходится, ничего не пишется.
* После записи скрипт перечитывает строки и только потом делает commit. Если столбец что-то обрезал (например, `pv` в `varchar(255)`), всё откатывается.

## Проверка

```bash
python -m unittest test_sc_exchange.py
```

Тесты используют SQLite вместо MySQL, поэтому база не нужна.
